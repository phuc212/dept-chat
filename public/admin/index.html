Phòng ban

Mỗi phòng chọn một nguồn tài liệu: tải file lên trực tiếp (.docx, .xlsx, .pdf, .txt, .md, .csv — không cần key) hoặc link thư mục Google Drive / SharePoint (cần key, bot tự đọc lại khi file đổi). Chưa có tài liệu = chỉ trả lời từ FAQ mẫu.

    Khoá kết nối

    Chỉ nhập được, không xem lại được: sau khi lưu, trang chỉ hiện “Đã có” và vài ký tự cuối để nhận ra.

    Đọc thư mục qua link chỉ cần khi có phòng chọn “🔗 Link thư mục” — phòng tải file lên thì bỏ qua
    Key Google (file key.json)
    Share từng thư mục phòng ban trên Drive cho email này, quyền Người xem:

    Chưa có key.json? Cách tạo (~10 phút)
    1. console.cloud.google.com → tạo project → APIs & Services → Library → bật Google Drive API.
    2. IAM & Admin → Service Accounts → Create (không cần role) → vào account → Keys → Add key → JSON → tải file về.
    3. Quay lại đây bấm Chọn file key.json → Lưu khoá. Xong thì xoá file trên máy nếu không cần nữa.

    Cần một app Microsoft Entra dùng chung cho mọi phòng. Nhờ IT: đăng ký app → tạo client secret → quyền Application Sites.Selected (admin consent) → cấp quyền read trên site chứa thư mục.

    Client secret

    Trả lời bằng AI tuỳ chọn — dán key Gemini hoặc Claude, hệ thống tự nhận

    Chưa có: bot trích đúng câu / dòng khớp nhất trong tài liệu. Có: AI đọc các đoạn đó rồi trả lời tự nhiên — vẫn chỉ dựa trên tài liệu, không dùng internet. Có nhiều AI thì thử lần lượt: Claude → Gemini → Workers AI; tất cả lỗi → tự quay về trích tài liệu.

    Lấy key ở đâu?
    • Gemini (có gói miễn phí): aistudio.google.com/apikey → Create API key. Ở gói miễn phí Google có thể dùng dữ liệu gửi lên để cải thiện sản phẩm.
    • Claude (trả phí): console.anthropic.com → Billing nạp credit → API Keys → Create Key.
    Workers AI (Cloudflare) miễn phí, không cần key — dùng khi không có key hoặc key lỗi
    Cách gắn (làm 1 lần trên Cloudflare)
    1. dash.cloudflare.com → Workers & Pages → dept-chat → Settings → Bindings → Add.
    2. Chọn Workers AI, Variable name gõ AI → Save.
    3. Deploy lại một lần (lệnh wrangler như mọi khi) → quay lại đây bấm Thử AI.

    Gói miễn phí: 10.000 "neuron"/ngày — khoảng vài chục tới một trăm câu hỏi mỗi ngày tuỳ độ dài tài liệu. Dữ liệu chạy trên Cloudflare, không gửi sang Google.

    Cài đặt chung

    Lưu ẩn danh câu hỏi, phòng, có trả lời được không, 👍/👎 — không lưu tên hay email người hỏi. Tự xoá sau 180 ngày.
    Tắt (mặc định): nhân viên chỉ thấy câu trả lời. Bật: thêm nhãn 📄 tên file đã dùng (chỉ tên, không mở / tải được file).
    Có thay đổi chưa lưu

    Xoá phòng “”?

    • Phòng và chatbot của phòng sẽ biến mất khỏi bản đồ.
    • Người dùng không hỏi được phòng này nữa; lịch sử chat đang mở sẽ mất.
    • Tài liệu trên Drive/SharePoint không bị xoá — thêm lại phòng với cùng link là dùng lại được.
    • File đã tải lên cho phòng này sẽ bị xoá theo.
    • Chỉ áp dụng khi bấm Lưu.

    Xoá khoá ?

    Xoá toàn bộ dữ liệu thống kê?

    Mọi câu hỏi, đánh giá 👍/👎 đã lưu sẽ bị xoá vĩnh viễn, không khôi phục được. Cấu hình phòng ban và tài liệu không bị ảnh hưởng.

    Xoá file “”?

    Bot sẽ không trả lời từ file này nữa. Muốn dùng lại thì tải file lên lần nữa.
